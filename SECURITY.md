# Security Policy

## Supported Versions

| Version        | Supported |
| -------------- | --------- |
| 2026.0.x-alpha | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in Kumbu, please report it responsibly.

**Do not open a public issue.** Instead, email [disclosure@oscar.co.tz](mailto:disclosure@oscar.co.tz) with:

- A description of the vulnerability
- Steps to reproduce
- Affected version(s)
- Any potential impact

You can expect an initial response within 72 hours. We will work with you to understand the issue and coordinate a fix before any public disclosure.

## Scope

This policy covers the Kumbu mobile application and its direct dependencies. Third-party services and libraries have their own security policies.
